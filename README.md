# Dante OS

Launcher Android pour téléphones rootés : pare-feu par app, filtre DNS, analyse du trafic, réglages du processeur et de la batterie. Aucun traqueur, aucune statistique.

Ce dépôt ne contient **que les versions installables** (onglet *Releases*). Le code source n'est pas publié.

## Installer et rester à jour

Avec [Obtainium](https://obtainium.imranr.dev/) : *Ajouter une app* → coller l'adresse de ce dépôt. Les mises à jour se font par-dessus, tes réglages sont gardés.

Ou à la main : télécharger `Dante-OS-<version>.apk` dans la dernière release, vérifier l'empreinte avec le fichier `.sha256`, installer.

Un guide complet est intégré à l'app (fiches, gestes, modules, transparence totale sur ce qu'elle lit, modifie et envoie).

Fourni « tel quel », sans garantie. Tu es responsable de ce que tu actives sur ton appareil.
